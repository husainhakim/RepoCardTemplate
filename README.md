# project_card --init

A lightweight, browser-based generator for creating terminal-themed project cards and SVG showcases for developer portfolios and GitHub READMEs.

**Live Demo:** [repo-card-template.vercel.app](https://repo-card-template.vercel.app)

---

## Overview

Most portfolio project cards look like generic SaaS marketing blocks. **project_card --init** generates brutalist, CLI-inspired project cards that prioritize technical clarity: problem statements, architectures, mechanics, and status indicators laid out like a native terminal session.

Cards can be customized directly in the browser and exported as crisp SVGs ready for Markdown integration.

---

## Features

* **Live Interactive Preview:** Updates in real-time as you tweak project metadata, tags, and commands.
* **Vector SVG Export:** Produces scalable, high-contrast SVGs designed for dark-mode interfaces and GitHub profiles.
* **CLI/Terminal Aesthetic:** Features macOS-style window chrome, custom execution commands, monospaced metadata grids, and status pill badges.
* **Client-Side & Private:** No trackers, telemetry, or backend data persistence.

---

## Getting Started

### Option 1: Use the Web App
1. Go to [repo-card-template.vercel.app](https://repo-card-template.vercel.app).
2. Fill out your project name, command flags, problem, method, and tech stack.
3. Add up to 3 status/topic tags.
4. Click **Download SVG** and embed it into your repository or site.
